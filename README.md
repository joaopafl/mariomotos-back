# mariomotos-back
Desenvolvimento back-end do App Mariomotos

MarioMotos

Aplicativo mobile de gestao de clientes, historico de servicos e agenda para oficinas de motocicletas. Desenvolvido como Projeto Interdisciplinar do 5o semestre do curso de Desenvolvimento de Software Multiplataforma (DSM), em parceria com a empresa MarioMotos.

Sobre o projeto

Oficinas de pequeno porte, como a MarioMotos, ainda controlam clientes, motocicletas, servicos prestados e agendamentos de forma manual. Isso gera conflitos de horario, atraso na entrega de servicos ja agendados e dificuldade de acompanhar o historico de manutencao de cada moto.

O MarioMotos digitaliza esse processo. A equipe da oficina passa a ter cadastro de clientes e motocicletas, registro de servicos, historico completo e uma agenda sem conflito de horario. O cliente passa a poder consultar o historico de servicos e os agendamentos da sua moto sem precisar ligar ou visitar a oficina.

Funcionalidades (MVP)
Autenticacao por perfil (Oficina / Cliente)
Dashboard com resumo do dia (Oficina) e proximo agendamento (Cliente)
Cadastro de clientes e de uma ou mais motocicletas por cliente
Registro e consulta de historico de servicos por motocicleta
Agenda de atendimentos com prevencao de conflito de horario
Consulta de historico e agendamentos pelo proprio cliente
Tecnologias utilizadas
Mobile: Flutter (Dart)
Backend / API: Node.js + TypeScript
Banco de dados: Firebase (Firestore)
Hospedagem da API: VPS
Versionamento: Git e GitHub
Gestao do projeto: Trello
Integracao continua: GitHub Actions
Prototipacao: Figma
Perfis de usuario

Oficina: equipe da MarioMotos, responsavel pelo cadastro e atendimento. Cliente: motociclista atendido pela oficina, com acesso somente leitura ao proprio historico e agenda.
